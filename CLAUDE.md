## Project Overview

"Plats du Jour" (PDJ) — a daily lunch menu aggregator for office restaurants. Two main components:

1. **Python backend** (`plats-du-jour/`): Scrapes menus from 6 restaurants — 3 core (Le Bistrot Trèfle, La Pause Gourmande, Le Truck Muche) + 3 optional (Basilic n'Go, Dubble, La Mijote : card « pas de plat du jour » + carte permanente notée les jours sans plat) — evaluates them with AI agents, generates comments from fictional characters, and publishes to the Vercel API. A 7th restaurant, Vival (épicerie avec bar à salades Picadeli en libre-service), is never scraped: link-only card on the frontend, clickable restaurant POI in the 3D view.
2. **Next.js frontend** (root): Displays the weekly menus with nutritional ratings, recommendations (two modes: "Sportif" and "Goulaf"), and a comment system. Deployed on Vercel.

### Python pipeline (`plats-du-jour/`)
```bash
cd plats-du-jour
source .venv/bin/activate
python main.py semaine              # Full weekly pipeline (Monday): scrape all menus + generate comments
python main.py jour                 # Daily pipeline: scrape today's dishes only
python main.py cartes [slug] [--force]  # Cartes permanentes (Trèfle, Basilic n'Go, Dubble, La Mijote) : scrape, hash, notation LLM si changement ; --force ré-évalue
python main.py images [YYYY-MM-DD|DEBUT..FIN|semaine] [--force]  # (POC) Images IA des plats publiés manquantes (semaine = lundi→vendredi, plage = jours ouvrés) ; --force régénère
python main.py recettes [YYYY-MM-DD|DEBUT..FIN|semaine] [--force]  # (POC) Recettes maison des plats publiés manquantes (mêmes dates) ; --force réécrit
python main.py memes [--dry-run]    # Gifs fétiches des IA rafraîchis depuis les memes du moment (meme.com + Giphy) ; --dry-run n'écrit rien
python main.py commentaires <name>  # Generate comments for one character
python main.py sync-feedback        # Sync human feedback into character profiles
```

## Architecture

### Data flow
Python scrapers → AI diet agent evaluation (LLM décompose en ingrédients + grammages, macros agrégées via table Ciqual) → AI comment generation → `publish.py` POSTs to `/api/update` → Vercel Postgres (`pdj_entries` table, JSONB column) → Next.js SSR reads from DB

Cartes permanentes : `main.py CARTE_SOURCES` → hash → `/api/carte` (`pdj_carte`, une ligne par slug), traitées le lundi ou via `main.py cartes`

Images IA des plats (POC) : `agent/image_agent.py` génère une photo par variante (`plat_image.a_illustrer`) : le LLM du pipeline rédige d'abord en un appel par lot une description visuelle anglaise de chaque plat (`plat_image.prompt_descriptions`, un essai borné, repli sur le libellé brut ; `PDJ_IMAGES_DESCRIPTION=off`), puis un fournisseur gratuit génère l'image, recadrée en WebP 768×512 par Pillow, (Cloudflare Workers AI si `CF_ACCOUNT_ID`/`CF_API_TOKEN`, AI Horde si `AIHORDE_API_KEY`, sinon Pollinations anonyme : 1 image / 45 s, logo laissé visible + crédit « Image : pollinations.ai » dans le panneau ; chaque fournisseur a une sous-deadline `PLAFOND_S`, Horde sauté si budget < 240 s) → POST `/api/plat-image` (Bearer) → table `pdj_plat_images` (bytea, clé = `sha256(norm(resto)|norm(plat))[:24]`, calculée à l'identique en Python `plat_image.py` et TS `lib/plat-image*.ts`, vecteurs partagés `lib/plat-image-vecteurs.json`). Best-effort : budget de 150 s après `publish_pdj` dans `jour`/`semaine` (hors `est_complet`), rattrapage par le cron `images semaine` de 10h35 (lock dédié `pdj_images.lock`, `timeout 1800`, ne bloque pas les runs jour/semaine) ; route `/api/plat-image/[cle]?v=` en cache CDN immuable (`s-maxage`), `v` faux → redirection ; `PDJ_IMAGES=off` coupe tout. Rien n'est écrit dans `pdj_entries`

Recettes maison (POC) : `agent/recette_agent.py` fait rédiger par le LLM (un appel par recette, 2 essais, même mécanisme API/CLI que les images) une recette maison inspirée de chaque variante (`plat_recette.a_cuisiner`, hors `coming_soon` / férié / jour sans plat), à partir du libellé et des ingrédients + grammages estimés du diet agent ; validée en Python (synonymes d'unités corrigés) puis par le serveur (`validerRecette`, liste fermée `UNITES`, 422 sinon) → POST `/api/recette` (Bearer) → table `pdj_recettes` (une ligne par plat, même clé que l'image : `clePlatImage`) + `pdj_recette_services` (une ligne par plat et date de service, alimentée aussi pour les plats déjà pourvus via `POST /api/recette/services`). Best-effort après les images dans `jour`/`semaine` (budget 180 s, hors `est_complet`), cron `recettes` à 11h15 lun-ven sur aujourd'hui seulement (lock dédié `pdj_recettes.lock`, `timeout 1800`) ; `PDJ_RECETTES=off` coupe tout. Notes Sportif/Goulaf + protéine recopiées côté Next depuis `pdj_entries` (`lib/recette-notes.ts` : note du dernier jour déjà servi — jours publiés d'avance ignorés —, protéine = `envieForPlat` ; une republication sans le plat recalcule les recettes notées ce jour-là, recalcul complet en une seule écriture) dans `pdj_recettes` : hooks best-effort de `/api/update`, `/api/recette` et `/api/recette/services`, rattrapage automatique des recettes `proteine IS NULL`, ou `POST /api/recette/notes {toutes?}` (Bearer) ; aucun changement Python. La recette n'est **pas** celle du restaurant : libellés imposés (« Recette maison inspirée du plat… »), jamais « recette du chef »

### Python pipeline structure (`plats-du-jour/`)
- `scrapers/` — One module per restaurant (`bistrot_trefle.py` uses the ObyPay REST API, `pause_gourmande.py` uses Playwright, `truck_muche.py` : menu hebdo publié en image sur Facebook → `requests` avec l'UA Googlebot (rendu SSR sans login, 302 intermittents depuis le VPS → jusqu'à 8 essais espacés) → post portrait/« texte » de la fenêtre samedi-précédent→maintenant → image `lookaside.fbsbx.com` (WEBP) → transcription par LLM vision (`agent/menu_vision_agent.py`, SDK ou CLI `claude` en stream-json) validée par `_menu_est_semaine_courante`/`_parse_menu_semaine` (≥ 3 jours) ; Instagram `web_profile_info` seulement en dernier recours (2 essais) ; cache hebdo `{lundi, menu, post_id}` rempli aussi hors lundi). Optionnels, synchrones (`requests`/urllib, sans Playwright) : `basilic_ngo.py` (API ObyPay comme le Trèfle, + `scrape_carte()` ObyPay), `dubble.py` (HTML Wix SSR, + `scrape_carte()` PDF saisonnier via pypdf), `la_mijote.py` (HTML statique + garde-fou fraîcheur `Last-Modified`, + `scrape_carte()` texte HTML sans plats du jour)
- `run_state.py` — État reprenable du run ; distingue `CORE_LABELS` (les 3 historiques, requis pour un run complet) et `OPTIONAL_LABELS` (`None` = « pas de plat du jour », pas un échec)
- `ciqual/` — Intégration de la table Ciqual ANSES pour le calcul déterministe des macros (cf. `ciqual/README.md`)
- `agent/diet_agent.py` — Claude-based nutritional evaluation (scores dishes 1-10 in both modes). Demande au LLM des ingrédients + grammages, agrège les macros via Ciqual, fallback LLM si >30% non matché.
- `agent/carte_agent.py` — Structuration LLM d'une carte à partir de texte brut (PDF Dubble, HTML La Mijote) + `_texte_hash` ; appelé seulement quand le hash change
- `agent/comment_agent.py` — Generates in-character comments from persona JSON files
- `agent/repair_team.py` — Auto-fixes scraper failures
- `agent/feedback_agent.py` — Syncs human comment feedback into character profiles
- `personnages/` — JSON files defining each character's personality, tone, food preferences (used by comment_agent)
- `messages.py` — Generates formatted message files for the week
- `jours_feries.py` — French public holidays detection
- `publish.py` — POSTs evaluation JSON to the Vercel API (+ `publish_plat_image`, `fetch_plat_images_existantes`, `fetch_pdj`)
- `plat_image.py` / `agent/image_agent.py` — Images IA des plats (POC) : clé, variantes, prompt, validation magic bytes (pur, testé) / fournisseurs + budget (cf. Data flow)
- `meme_fetiches.py` / `agent/meme_agent.py` — Gifs fétiches des IA (cron lundi 6h45, avant le run semaine, lock `pdj_memes.lock`) : memes « Trending Now » + flux `recent.xml` de meme.com (filtre NSFW/politique `MOTS_EXCLUS`), casting LLM (4 memes par IA, uniques, ceux de la semaine passée exclus), version animée Giphy sinon image meme.com, URL vérifiée → `PUT /api/ia` (15 écritures/min, pause entre profils). Un gif automatique porte le fragment `#meme-auto=<slug>` : seuls ceux-là sont remplacés, les gifs ajoutés à la main restent en tête ; `comment_agent` retire le fragment avant de donner l'URL au LLM
- `plat_recette.py` / `agent/recette_agent.py` — Recettes maison (POC) : variantes à cuisiner + dates de service (pur, testé, réutilise `plat_image.cle_image`) / prompt, validation du schéma, appel LLM, budget (cf. Data flow) ; cron 11h15, lock `pdj_recettes.lock`, `PDJ_RECETTES=off`

### Two evaluation modes
Every dish gets two scores: "Sportif" (health-focused) and "Goulaf" (taste/indulgence-focused). The frontend toggles between them client-side : état React `useModeSite` (`localStorage` `pdj-mode` + événement `pdj:mode-refresh`), partagé avec la vue 3D.

## Key conventions

- Thèmes (`app/globals.css`, blocs `html[data-theme="normal|tigre|terrasse"]`, préfixés `html` pour ne pas fuir sur les boutons `.theme-btn[data-theme]`) : contraste AA visé partout. Contours de champs/boutons en `--border-control` (≥ 3:1), `--border` réservé aux tuiles et séparateurs ; fonds teintés d'état/note en tokens opaques `--accent-soft` / `--good-soft` / `--ok-soft` / `--bad-soft` (le pelage tigre passe sous les fonds translucides) ; jamais de couleur Tailwind en dur (`gray-*`, `red-*`, `white`) ni d'`opacity` pour atténuer du texte
- The app is entirely in French (UI text, comments, API error messages, variable names in domain code)
- Dates use `YYYY-MM-DD` format (ISO via `toLocaleDateString('en-CA')`)
- `@/*` path alias maps to project root
- Database: single `pdj_entries` table with `date` (unique) and `data` (JSONB containing full `PdjEntry`) ; `pdj_plat_images` (POC images IA) créée par `ensurePlatImagesTable()` et `lib/migrate.mjs` ; `pdj_recettes` (POC recettes, clé = clé du plat, colonne `recherche` normalisée pour la recherche sans `unaccent`) et `pdj_recette_services` (cle, date) créées par `ensureRecettesTable()` et `lib/migrate.mjs` ; colonnes `note_sportif`, `note_goulaf`, `note_date`, `proteine` de `pdj_recettes` (ALTER conditionnel dans `ensureRecettesTable`, lectures tolérantes au code 42703)
- `pdj_tigre_scores` (classement de la chasse au tigre, index `(score DESC, created_at)`) créée par `ensureTigreScoresTable()` (une fois par processus, avant la première lecture ou écriture) et `lib/migrate.mjs`
- The `/api/update` endpoint is protected by `API_SECRET_TOKEN` (Bearer auth)
- Le `RootLayout` ne lit ni cookies ni en-têtes : toute page serveur qui lit la DB doit déclarer `export const dynamic = "force-dynamic"`, sinon elle est figée au build
- Python deps: `playwright`, `anthropic`, `python-dotenv`, `requests`
- Environment: `.env.local` for Next.js (Vercel Postgres vars + API_SECRET_TOKEN), `plats-du-jour/.env` for Python (same token + VERCEL_API_URL + ANTHROPIC_API_KEY ; optionnels images IA : CF_ACCOUNT_ID/CF_API_TOKEN, AIHORDE_API_KEY, PDJ_IMAGES*, cf. `.env.example`)
